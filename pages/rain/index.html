Signing happens entirely on this device; each Schnorr signature is re-verified against the funder's UTXOs before the hex is shown. Only the finished transaction is ever broadcast. Use the air-gapped paste mode on a machine you trust.

Honest limits

  • This tool moves real PRL when you broadcast. There is no undo.
  • Max 250 recipients per transaction (relay standardness headroom).
  • Only Pearl v1 Taproot addresses (prl1p…) are accepted — no legacy formats exist on Pearl.
  • Amounts below 546 grains are rejected as dust; dust change is folded into the fee.
  • UTXO fetching and broadcast need a Blockbook endpoint you configure (mainnet default: https://blockbook.pearlresearch.ai). The air-gapped paste mode never touches the network until broadcast.
  • No send was executed during development — this page needs your funds and your explicit broadcast.
