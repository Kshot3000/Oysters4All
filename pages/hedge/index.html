Write the option

The writer locks qty PRL collateral in a two-leaf Taproot vault under a nothing-up-my-sleeve internal key. The buyer can take the collateral at or after the expiry block by revealing a secret preimage and signing; after expiry the writer can reclaim it. Pearl has no smart contracts — this is pure Taproot script.

Buyer hashlock secret (32 bytes) — hand this to the buyer and keep no copy. It is revealed only at exercise.

Honest limits

    
    
      
  • The Taproot script enforces collateral routing only: buyer-with-preimage at/after expiry, or writer after expiry. It cannot atomically verify the buyer's off-chain strike payment on-chain — the desk checks the strike txid on Blockbook before the buyer's exercise tx is built.
    • 
      
  • No real options were exercised in testing — all exercise/refund flows were verified against synthetic UTXOs in a real browser.
    • 
      
  • The premium is a pledged off-chain payment. The desk never escrows it and cannot enforce it.
    • 
      
  • Exercise before the expiry block is impossible on-chain (CLTV). Refunds before expiry are refused. After expiry there is a race: the writer should confirm no buyer exercise before refunding.
    • 
      
  • Expiry is a block height; the days→blocks conversion uses ~194 s/block and is approximate. Only deal with counterparties you trust.
    • 
      
  • Not financial advice. Test on testnet first.
