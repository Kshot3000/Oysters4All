Pearl Escrow

Bonded Taproot 2-of-3 escrow for PRL

The parties

Three keys seal the bond: buyer, seller and arbiter. Any two of the three can release the funds. If they never agree, the refund key can sweep everything back after the timelock. Paste a 64-hex x-only pubkey or a 12/24-word mnemonic per party — mnemonics never leave this page.

Buyer funds the escrow · default refund key

Seller receives on release

Arbiter breaks ties, never unilateral

The contract

The escrow address commits to both spending paths. Verify the scripts before anyone funds it — the address is fully determined by the three keys, the refund key and the lock height.

Security notice (2026-09-29): escrow addresses forged before this fix used the buyer's key as the Taproot internal key, which left a keypath backdoor — the buyer could spend unilaterally. This page now derives a NUMS internal key with no known private key (shown below as “NUMS — no known private key”). If you hold an address from an older build, do not fund it; re-forge the contract here and confirm the address changes before depositing.
