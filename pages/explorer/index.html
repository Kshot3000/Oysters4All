    RPC settings

    The explorer calls getinfo, getblockcount, getblockhash, getblock and getrawtransaction on the endpoint you configure. Your node must allow browser requests:

    # pearld RPC is mainnet :44107 by default. Browsers can't reach it directly
# unless it serves CORS headers — easiest is the upstream node/proxy
# Caddy sidecar (TLS + CORS), or serve this page from the node host.

    Credentials are stored only in this browser's localStorage and sent to your endpoint via HTTP Basic auth. Never point this at an RPC endpoint you don't control.
