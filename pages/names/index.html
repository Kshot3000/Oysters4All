Pearl Names

The Pearl address book — bind a memorable name.prl to your prl1… Taproot address. Sign it with your own key, seal it on-chain, let anyone verify it.

Honest limits

  • A name proves control of a key — not a real-world identity, not trustworthiness, not humanity.
  • The Directory below is a local registry (this browser). Global first-seen needs a public prl-name indexer, which doesn't exist yet — until then, resolve conflicts on-chain yourself.
  • Names do not replace addresses. A wrong name still resolves to the recorded address; always confirm the prl1… string before sending funds.
  • Inscribing costs real PRL (commit + reveal fees) and cannot be undone. The wizard shows exact hex before anything is built.

Register a name

Four steps: pick a name, prove you hold the address's key, plan the on-chain inscription, broadcast.

Step 1 · Choose a name

3–63 chars, a–z 0–9 and single hyphens, not all digits, not reserved. Shown with the .prl suffix.

Step 2 · Prove ownership

Load the BIP-86 key for the address you're naming (mnemonic, WIF, or raw hex). Keys live in this page's memory only — they are never sent anywhere. Signing builds a BIP-340 proof that the claimed address's key signed this exact record.
