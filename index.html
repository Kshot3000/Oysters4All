Layer-1 · Proof-of-Useful-Work · PRL

The chain secured by useful work.

Pearl replaces Bitcoin-style hash puzzles with arbitrary matrix multiplication — the same computation GPUs perform for AI inference. The work that secures the network can simultaneously serve real compute demand.

The protocol

Wasted hashes, replaced.

Every Pearl block is backed by verifiable, useful computation — not lottery tickets.

🧮

Useful work

Mining is a by-product of arbitrary matrix multiplication. Rigs that secure Pearl are doing math the world actually needs — AI training and inference.

🔏

ZK-PoW certificates

Each block carries a Plonky2 / STARKy zk-SNARK certificate proving the work was done — verifiable by every node, cheap to check.

🛡️

Post-quantum ready

XMSS hash-based signatures and dedicated post-quantum opcodes harden Pearl against quantum adversaries from day one.

🔑

Taproot-only

Every address is a Taproot address (prl1p…) with Schnorr signatures — private, compact, and script-capable by default.

Mining

Mine with the GPU you already have.

Pearl's reference miner is built on vLLM — the high-throughput LLM inference engine. Your mining rig is an AI compute rig; the chain just certifies the math.

  1. Run pearld — build or download the full node and sync.
  2. Start the vLLM miner — point it at your node over JSON-RPC.
  3. Earn PRL — block rewards for certified useful work.
Miner source ↗ Full monorepo ↗
quickstart.sh
# 1. Build the node (Go 1.26+, Rust, C toolchain)
task build:pearld

# 2. Run it (mainnet)
./pearld --mainnet

# 3. In another shell — start mining
cd miner && uv run pearl-miner \
  --rpc-user youruser \
  --rpc-pass yourpass \
  --payout-address prl1p…
