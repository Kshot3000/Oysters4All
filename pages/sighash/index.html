Honest limits — read before you draft

  • Educational reference implementation, not consensus code: the digest math is real and pinned byte-for-byte against the official BIP-341 wallet test vectors (all 7 sighash flags) plus the full BIP-340 vector set, but this page is not pearld and makes no claim of interop with it. Review src/sighash-core.js before trusting it with real money.
  • Demo values are labeled demo: the built-in scenario uses invented txids and keys. Nothing here touches a chain, a wallet, or a node — every digest is computed locally from what you type.
  • SIGHASH_SINGLE is refused loudly when the input index has no corresponding output — consensus would fail that signature too.
  • Keys live in this page's memory only. Anyone watching your screen or with access to this browser session sees them. Wipe them when done.
  • Annexes are exotic: the annex path (spend_type low bit, sha_annex) is implemented per BIP-341, but no mainstream wallet produces annexes yet — treat it as a drafting exercise.
