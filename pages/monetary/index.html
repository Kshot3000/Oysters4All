Pearl · Monetary Desk

Pearl Monetary

The central-bank desk for PRL. Every block subsidy on Pearl is minted by one formula — no halvings, no governance votes, just a smooth exponential decay written into node/blockchain/validate.go. This desk recomputes it exactly (BigInt, grain-for-grain) in your browser: the live era, the full issuance curve, the era schedule, and explorer tools. No backend, no wallet, no keys.

Honest limits — always true:
  • All figures come from the exact upstream subsidy formula (CalcBlockSubsidy); dates are estimates at 194 s/block — real block times vary, so treat every date as approximate.
  • Live height comes from the public Blockbook API (blockbook.pearlresearch.ai/api/v2). If it is unreachable, the desk falls back to a dated, labeled stale snapshot — never a silent guess.
  • Cumulative supply uses the closed-form S·h/(h+C); it equals the true sum of per-block subsidies to within one grain per block of truncation.
  • This page never moves PRL, never holds keys, and predicts nothing about price.

Coinbase maturity explainer

Pearl requires 100 confirmations before a coinbase output is spendable (chaincfg: CoinbaseMaturity = 100). At the 194 s target that is about 5 h 23 min after the funding block — an estimate, not a promise.

Methodology & sources

The formula

Pearl's block subsidy is the exact discrete difference of the issuance curve S·h/(h+C):

subsidy(h) = ⌊ S · C / ((h + C) · (h − 1 + C)) ⌋   grains,  h ≥ 1
subsidy(0) = 0                                            (genesis pays nothing)

S = 2,100,000,000 PRL × 10⁸ grains/PRL   (max supply)
C = (4 × 365 × 86,400 s) / 194 s = 650,226 blocks   (emission constant, ~4 years)

Sources

  • node/blockchain/validate.go — CalcBlockSubsidy (big.Int division, truncated; genesis special-cased to 0).
  • node/blockchain/emission_test.go — upstream test vectors (e.g. h=650226 → ~807.412 PRL, h=1300452 → ~358.850 PRL); this desk's unit tests pin the same vectors grain-for-grain.
  • node/chaincfg/params.go — TargetTimePerBlock = 3 min 14 s (194 s), CoinbaseMaturity = 100.
  • node/btcutil/const.go — GrainPerPearl = 1e8.
  • Live height: GET https://blockbook.pearlresearch.ai/api/v2 → blockbook.bestHeight (fallback: backend.blocks).

Honesty notes

  • Dates are estimates at exactly 194 s/block from a labeled anchor — difficulty retargets and real block times drift, so ±days of error per projected year is normal.
  • Cumulative supply is the closed form ⌊S·h/(h+C)⌋; the true sum of per-block subsidies is never larger and differs by at most one grain per block.
  • Subsidy never reaches zero on this curve — it decays forever toward zero (at height 32,511,300 it is still ~1.24 PRL/block).
