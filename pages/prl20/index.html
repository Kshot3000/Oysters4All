About PRL-20

Pearlscriptions are Ordinals-style inscriptions on Pearl's Taproot-only chain. PRL-20 is the inscription-based token standard: a deploy inscription defines a ticker (tick), max supply (max), per-mint limit (lim) and decimals (dec); mint and transfer inscriptions move balances. State is derived by independent indexers and exposed through the read-only HTTP API this dashboard uses.

Docs: API contract · PRL-20 v0 spec · pearlscriptions.com
