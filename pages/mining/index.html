How Pearl mining works

⚙ Useful work, not busywork

Pearl replaces hash grinding with Proof-of-Useful-Work: miners run real matrix multiplications as a by-product of LLM inference (vLLM + NoisyGEMM CUDA kernels). The work is useful and secures the chain. Paper: arxiv.org/abs/2504.09971.

💻 Hardware

The reference miner is a vLLM plugin. It needs an NVIDIA GPU (currently sm90 — H100 / H200), CUDA toolkit, Python 3.12 and uv. Source: miner/ in pearl-research-labs/pearl.

🔒 ZK-PoW certificates

Blocks carry ZK-PoW certificates (Plonky2/STARKy) that prove the useful work was done. Since the salted-seed hard fork (mainnet height 99000), getblocktemplate reports requiredcertversion: 3 — miners must submit V3 salted noise-seed certificates.

⏱ Payout rhythm

One block every ~3m14s → ~445 blocks/day. Coinbase outputs mature after 100 blocks (~22.5 hours) before they can be spent. Difficulty retargets with a WTEMA filter, so network growth smoothly raises difficulty.

Quickstart (from the upstream miner README)

git clone https://github.com/pearl-research-labs/pearl && cd pearl
uv sync --package vllm-miner        # builds pearl-gemm CUDA kernels
# point the miner at your pearld via pearl-gateway, then run the vLLM plugin

Full build + test instructions live in the upstream miner/README.md. Docker one-click images exist from the community (see the ecosystem survey) — verify any third-party image before trusting it with your keys.
