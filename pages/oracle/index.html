Honest limits

  • A signature proves authorship, not truth — prices are self-reported by whoever holds the key.
  • Anyone can mint an oracle key. A pretty pubkey is not a credential.
  • This feed is local-only: no listing relay, no shared network, nothing is broadcast.
  • Replay is stopped only inside a chain a consumer chooses to trust (seq + prev links).
  • Timestamps are asserted, not proven — ±24h sanity is a warning, not a proof.
  • This page never moves PRL and never broadcasts anything.
