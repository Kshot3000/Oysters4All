Honest limits

  • The NUMS internal key has no known private key — spending is possible only through the multisig script leaf. There is no keypath escape hatch, by design.
  • The quorum is enforced by the Bitcoin-script CHECKSIGADD leaf on Pearl's Taproot — it is a chain rule, not an app convention.
  • Partial signatures are verified against the claimed cosigner key and the exact per-input BIP-341 digest before acceptance. A bad signature never reaches the chain.
  • Fees are computed from the exact script-path witness weight. Change below 546 grains is added to the fee and disclosed — never stranded.
  • Keys you enter stay in this page's memory; use the wipe button when done. The page never uploads keys anywhere.
  • Blockbook reads are third-party data; an unreachable Blockbook means no balances, no broadcast — the page says so loudly instead of guessing.
