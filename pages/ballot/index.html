The voting rules (published with the descriptor)

  • One address, one ballot. A second ballot from the same address is flagged — first valid ballot wins.
  • Ballots are signed inside the voting window only (chain tip between start and end height).
  • Weight = the voter's current confirmed PRL balance from Blockbook, recorded in the signed ballot. The snapshot height is the organizer's enforcement reference (see Honest limits).
  • Every ballot signature is re-verified at tally time against the voter's address key. Wrong-key or tampered ballots are loudly refused.
  • Exact ties are reported as a TIE — the page refuses to pick a winner out of thin air.

      Honest limits

      • No PRL ever moves through this page. It drafts proposals, signs ballots locally, tallies signed ballots, and verifies polls — governance results are social consensus, not on-chain execution. Pearl has no smart contracts; nothing on-chain enforces the outcome.
      • Fairness is a signed-ballot protocol, not code: the guarantee is that the descriptor must be published before the voting window opens — anyone can then re-hash the proposal and re-verify every ballot signature. A descriptor that appears only after the window opened proves nothing.
      • Voting weight is the CURRENT confirmed balance from Blockbook, not a read at the snapshot height — Blockbook does not expose historical address balances. Snapshot-height enforcement is the organizer's job; the claimed snapshot height is recorded inside every signed ballot so anyone can cross-check it against their own pearld node.
      • Ballot relay is manual: voters publish signed ballots publicly (forum, Discord, X) and the organizer imports them. The page cannot prove when a pasted ballot was created — in-page signing refuses out-of-window votes, but pasted ballots rely on the organizer's honest collection.
      • One address, one ballot — but nothing stops one person from voting under two different addresses. Know your voters.
      • Keys entered on the Vote step live in page memory only and are never stored or sent anywhere; use the Wipe button when done.
      • Blockbook is a third-party read source; for polls that decide real money, confirm heights and balances with your own pearld node — the manual-tip paths exist for exactly this. Block countdowns assume the 194-second target block time.
      • No real vote has been conducted through this page. All signatures and tallies were exercised in tests and headless-browser QA with synthetic keys.
