Pearl Node

A read-only mission-control console for your own pearld node — chain status, peer table, mempool depth, and mining telemetry over JSON-RPC. This page never sends state-changing RPCs and never touches your wallet.

not connected
Honest limits — always true:
  • This console is read-only: it only ever calls getinfo, getmininginfo, getmempoolinfo, getpeerinfo, getnettotals, getchaintips. It cannot stop your node, change config, or move funds.
  • Browsers cannot call pearld directly — pearld sends no CORS headers and uses a self-signed TLS cert by default. Run the bundled relay.mjs on the node machine (read-only methods only) and point this page at it. Direct connections will fail loudly, not silently.
  • pearld's RPC is disabled until you set rpcuser + rpcpass (or rpclimituser/rpclimitpass). Without credentials every call returns 401.
  • Health notes are heuristics, not consensus: a green lamp means the node answered and looks sane, not that the chain is final.
  • Credentials live in your browser's localStorage — anyone with your browser profile can read them. Use a dedicated RPC user with a strong password.

    Mempool getmempoolinfo

    pearld exposes mempool size and bytes only — there is no fee histogram endpoint, so this console shows depth, not fee pressure. Average tx size is bytes ÷ count.

    Mining telemetry getmininginfo

    generate tells whether this node is set to mine locally; hashespersec is its own recent rate while generating. networkhashps is the whole network's estimate. Pearl has no staking — don't look for it here.

    RPC connection

    Saved in this browser's localStorage under pearl-node-settings. The password is stored as typed — treat this browser profile as holding a credential.

    Run the relay relay.mjs

    On the machine running pearld (zero dependencies, Node 18+):

    PEARLD_RPC=http://127.0.0.1:44107 \
PEARLD_USER=your-rpcuser PEARLD_PASS=your-rpcpass \
node relay.mjs
# → listening on http://127.0.0.1:44120 (loopback only)

    The relay forwards only the six read-only methods this console uses, adds CORS headers, and binds to 127.0.0.1. For testnet use PEARLD_RPC=http://127.0.0.1:44109; for a --notls node the http:// URL is correct. If you run pearld with default TLS, keep the relay on the same host — it accepts the node's self-signed cert on your behalf; the browser never sees it.

    Enable RPC on pearld

    RPC is disabled unless credentials are set. In pearl.conf:

    rpcuser=your-rpcuser
rpcpass=a-long-random-password
# optional: rpclisten=127.0.0.1:44107

    Restart pearld after changing the config. Method names and ports verified against upstream node/docs/json_rpc_api.md (mainnet RPC 44107 / P2P 44108, testnet 44109/44110, testnet2 44111/44112).
