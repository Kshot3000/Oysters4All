Exact unit conversion

Pearl's smallest unit is the grain (upstream node/btcutil/const.go: 1 PRL = 100,000,000 grains). wPRL is 18 decimals, so 1 grain = 1010 wei, exactly (grains → wei: × 1010; wei → grains: ÷ 1010, sub-grain dust truncated).

FAQ

How does the bridge work?

The Pearl L1 is Taproot-only with no smart contracts, so wPRL follows the wBTC model: you send native PRL to the operator's vault (plus a 0.25% fee output, plus an OP_RETURN memo naming your Base address). After 6 confirmations the operator verifies the tx and calls mintDeposit on the Base bridge contract, minting you exactly 1 wPRL per PRL. To unwrap, you call requestWithdraw: 0.25% goes to the fee address on-chain, the rest burns, and the operator releases the net PRL to your prl1… address.

Is this trustless?

No — it is custodial, like wBTC. The backing PRL sits in the operator's vault off-chain, and you trust the operator to hold 1:1 backing and release PRL on burns. Mitigations: immutable fee recipient, per-txid replay protection, on-chain supply accounting, a public proof-of-reserves dashboard, an admin pause brake, and (planned) multisig operator keys plus a professional audit before any mainnet.

Which "PRL" is this?

Only the native token of the Pearl Proof-of-Useful-Work L1 (pearl-research-labs/pearl). It is not Oyster Pearl, not Perle on Solana, and not any copycat "PRL". The branding on this page says which PRL everywhere for exactly that reason.

Why testnet only?

The contracts, operator and this site are built and tested, but no audit, custody setup or legal review has happened yet. Until those are done — and Kyle gives explicit written go-ahead — everything targets Base Sepolia and no real funds should be used. Mainnet deployment is a deliberate, announced event, not a quiet config flip.

What if my deposit is missing the fee output or the memo?

It is not auto-minted. Your PRL stays safe in the vault and the tx is logged for manual review — the custodian can refund it. Double-check the generated instructions before sending.

What does the operator run?

Open-source Node operator: a Pearl deposit watcher (pearld searchrawtransactions, needs --addrindex), a Base withdrawal watcher (idempotent per nonce, 2-block reorg margin), and the /reserves API behind the dashboard above. Full source and runbook in the repo.
