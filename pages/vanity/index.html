How the forge works

  1. Each attempt draws a secret key, computes its x-only public key (secp256k1), and encodes bech32m(hrp, v1, key).
  2. If the address opens with prl1p + your prefix, the key is yours.
  3. The address is the public key — no tweak, no script. The secret signs keypath spends directly.

Before you fund it

  • Send a tiny test amount first, then spend it back, to prove you hold the key.
  • BIP-86 mode keys are recoverable from your seed + the path above; random-mode keys are not.
  • This page never sent your key anywhere — but your browser, extensions, and screenshots can see it. Treat the revealed key as exposed.
  • Grinding is probabilistic: the forge got lucky, not smart. Longer prefixes need exponentially more luck.

Honest limits

  • Vanity grinding is pure chance: expected attempts = 32n. A 5-character prefix averages 33.5M attempts — an overnight job, not a coffee break.
  • Browser grinding is slow next to GPU rigs; this forge is for short, fun prefixes.
  • A vanity address is exactly as secure as a random one — the prefix buys memorability, nothing else.
  • All crypto (secp256k1, bech32m, BIP-86) is vendored from the audited Pearl Sign core — no new cryptography, only key-generation loops.
